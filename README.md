# SF Empire Offline v0.2 — 통합 베타

이 버전은 **인터넷/API 없이 GGUF 로컬 모델을 SF 우주 제국 GM으로 사용하는 Android APK**입니다.

## v0.2에서 추가된 것

- SF Empire 전용 다크 UI
- `rules.txt` 전체를 APK 자산에 포함
- 컨텍스트 절약용 `core_rules.txt` 자동 주입
- 플레이어 행동 키워드에 따라 원본 규칙 관련 절을 추가로 주입하는 간단한 로컬 규칙 검색
- `<think>...</think>` / `<analysis>...</analysis>` 화면 숨김
- 선택한 GGUF를 앱 내부 저장공간으로 복사 후 다음 실행에서 자동 로드
- 자동 저장
- `저장` / `불러오기` 1개 슬롯
- `새 게임`
- 앱 Manifest에 INTERNET 권한이 없는지 빌드 단계에서 검사

## 설치/업데이트

1. 저장소에 이 ZIP의 내용을 업로드합니다.
2. Actions → `Build SF Empire Offline v0.2 APK` 실행이 끝날 때까지 기다립니다.
3. 성공한 실행의 Artifacts에서 `SF-Empire-Offline-v0.2-APK`를 받습니다.
4. ZIP을 풀고 APK를 설치합니다.
5. 이전 테스트 APK와 서명 충돌로 설치가 안 되면 **기존 테스트 APK를 삭제한 뒤 설치**하세요.
6. 처음 실행 시 `모델` → 휴대폰의 `.gguf` 선택.
7. 모델 복사는 수 GB라 첫 1회 오래 걸릴 수 있습니다.
8. 준비 완료 후 `새 게임`을 누릅니다.

## 권장 테스트 모델

처음에는 4B Q4 계열을 권장합니다. 이미 휴대폰에서 정상 동작을 확인한 모델이 있다면 그 GGUF를 그대로 선택하세요.

## 세이브 동작

- 대화 기록은 자동 저장됩니다.
- `저장`은 별도 슬롯 1개에 현재 기록을 복사합니다.
- `불러오기`는 해당 기록을 복원하고, 다음 입력 때 핵심 규칙 + 최근 기록을 다시 AI에 주입합니다.
- v0.2는 아직 숫자 자원/함대/연구를 별도 구조체로 계산하는 완전한 게임 엔진은 아닙니다. 그 부분은 v0.3 목표입니다.

## 컨텍스트 절약

513줄 원본 규칙 전체를 매번 모델에 넣지 않습니다. 대신 핵심 압축 규칙을 기본으로 쓰고, 사용자의 현재 행동에 `연구`, `함대`, `행성`, `외교` 같은 키워드가 있을 때 해당 원문 절을 필요할 때만 추가합니다.

## 완전 오프라인 확인

설치와 GGUF 준비가 끝난 뒤 **비행기 모드**에서 게임을 진행해보세요. 빌드 워크플로는 Manifest에 `android.permission.INTERNET`가 있으면 실패하도록 되어 있습니다.
